Semiconductor Roadmap · 后摩尔时代

韬 / τ 定律
vs 摩尔定律

一个是被半导体产业验证几十年的“几何缩微”经验规律；一个是华为提出的、面向后摩尔时代的“时间缩微”工程路线。

摩尔定律靠“空间缩小”：晶体管越做越小。
韬 / τ 定律靠“时间缩短”：信号少绕路、少等待、系统更高效。

1. 什么是韬 / τ 定律？

“韬定律”更准确可写成 韬 / τ 定律。这里的 τ 是希腊字母 tau，常用于表示时间常数或某种时间尺度。

其核心思想是：未来芯片性能提升不应只依赖把晶体管做得更小，还可以通过缩短信号传播时间、减少等待、减少数据搬运、优化电路/芯片/系统结构来提升性能。

传统路线：几何缩微 → 更小晶体管 → 更高密度 / 更低功耗 / 更高性能
τ 路线：时间缩微 → 更短路径 / 更低延迟 / 更高系统效率
时间缩微 关键路径优化 互连延迟 系统协同 封装 / 3D / Chiplet

一句话理解

如果说摩尔定律像是把路修得更窄、更密，让同样面积里塞进更多车道；

那韬 / τ 定律更像是重新规划路网，让车少绕路、少等红灯、少堵车，即使发动机不变，也能让整体速度变快。

它更像工程方法论或技术路线，而不是物理学意义上的自然定律。

2. 和摩尔定律的核心区别

空间缩微 vs 时间缩微
对比点 摩尔定律 韬 / τ 定律
核心变量 晶体管数量、晶体管密度、制程节点 时间延迟 τ、信号传播时间、关键路径、系统执行时间

Moore's Law

摩尔定律：含金量更高

摩尔定律虽然也不是自然定律，而是经验观察，但它背后对应的是几十年真实产业进步：光刻、材料、器件结构、EDA、制造良率和供应链的整体演进。

它的强大之处在于：产业真的长期做到了“更小、更密、更强、更便宜”的复合进步。

Tau Scaling

韬 / τ 定律：现实意义在补偿

当先进制程越来越贵、越来越难，甚至某些企业拿不到最先进光刻和制造资源时，就必须从非制程维度继续挖掘性能。

这包括减少互连延迟、优化数据移动、提升封装效率、做芯片间高速互联、做软硬件协同，以及在系统层面提升真实吞吐。

3. 能否替代摩尔定律？

不能简单说韬 / τ 定律已经替代摩尔定律。

更准确的关系是：摩尔定律变慢以后，韬 / τ 定律试图从“非制程维度”继续提升性能。

如果先进制程继续推进，几何缩微仍然非常有价值；如果制程受限，那么时间缩微、系统协同和架构优化就会变得更重要。

4. 关键风险与验证点

韬 / τ 定律不是玄学，它对应的许多方向本来就是芯片设计中的真实问题，例如 RC 延迟、互连瓶颈、封装、3D 堆叠、Chiplet、数据移动成本等。

但真正的问题是：宣称的性能、密度、功耗、散热、良率、成本，能不能在真实产品和大规模量产里兑现。

5. 汽车类比

摩尔定律

像是不断换更大马力、更高热效率、更高转速、更先进材料的发动机。

韬 / τ 定律

像是优化变速箱、传动效率、车重、风阻、轮胎抓地、ECU / TCU 标定，让同样发动机跑得更快。

最终判断

摩尔定律的产业含金量更高，因为它已经被历史验证。

韬 / τ 定律的现实意义在于：在先进制程受限、摩尔定律放缓、AI 芯片对通信和数据搬运极度敏感的背景下，企业必须从架构、互连、封装、系统软件中继续榨性能。

所以它们不是“谁打败谁”的关系，而是：

摩尔定律负责把晶体管做得更小；
韬 / τ 定律试图让已有晶体管和系统跑得更聪明。
